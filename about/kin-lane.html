Kin Lane is the founder and operator of API Evangelist. Kin has been in the technology industry for 35 years, with the last 16 years dedicated to HTTP APIs. During that time he has served as a Presidential Innovation Fellow in the Obama administration, worked with the European Commission on API standards, been Chief Evangelist for Postman, stood up an API governance program at Bloomberg, and is now co-founder of Naftiko, where he is helping enterprises turn their existing data and APIs into governed capabilities for AI. Via API Evangelist, Kin continues to distill that experience into informative and actionable knowledge bases and services that help enterprises make sense of the API sprawl accumulated throughout this century.

API Evangelist is built upon years of Kin Lane working with companies, organizations, institutions, and government agencies on API strategy. The API Evangelist approach is not driven by profit motivation, but by a strong passion for understanding the technology, business, and politics of doing APIs at scale. API Evangelist generates revenue through knowledge, artifacts, partnerships, and services, and is not venture backed. The focus is on the internal and external relationships enterprises have with the markets they operate in—and you can trust that API Evangelist will always provide an expert, independent view of what is actually happening in any business sector when it comes to APIs and the AI agents that increasingly depend on them.
