This website is a static, API-driven toolbox that API Evangelist uses to make sense of the public API landscape, developing strategies, policies, and rules that can be used to discover and govern APIs within the enterprise. The site is a federated mix of 30+ separate GitHub repositories, APIs, and static websites that survey and assess thousands of other APIs, distilling their operations into individual repositories that can be forked and used anywhere.

Each of the subdomains within the API Evangelist website contains information focused on the surveying and assessment of HTTP APIs at scale, with the knowledge of how to do it offered as knowledge bases and services that any company, organization, institution, or government agency can purchase. This is version 4.0 of the API Evangelist platform—first launched in 2010—and notably this version is 100% out in the open, demonstrating how anyone can survey and assess the API landscape within any industry or enterprise. The patterns refined here are the same ones now powering Naftiko's work on governed capabilities for AI.
