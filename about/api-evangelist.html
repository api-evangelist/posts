API Evangelist is the working toolbox of Kin Lane, designed to explore and make sense of the technology, business, policies, and people involved in creating and consuming HTTP APIs. The site serves as an evolving repository of information that covers nearly every aspect of API operations. The goal of the site is to help enterprises, startups, analysts, consultants, and other stakeholders assess, manage, and govern the increasingly expansive API landscape that powers the applications, agents, and business sectors we depend on.

This site is built on 16 years of experience working with APIs, compiling insights, artifacts, and videos to document and analyze the intersection of technology, business, policies, and people shaping the API ecosystem. API Evangelist works to provide practical, hands-on knowledge that can be applied directly to operations. API Evangelist delivers content in machine-readable formats, complemented by meaningful narratives that address the needs of both engineering and product teams—while minimizing vendor lock-in to help organizations build their own platforms and capabilities.

The work done here feeds directly into the broader API Evangelist ecosystem, including APIs.io for API discovery and search across the landscape, and API Commons for the open standards and definitions that make APIs reusable across teams and organizations.
