Cloudflare's new isitagentready.com scanner gave apievangelist.com an 83 — Level 5, 'Agent-Native'. Discoverability, content, and bot access control all came back 100%. The four-out-of-six on API/Auth/MCP/Skill discovery was the only place the score got dinged, and the two misses were the two OAuth checks — which don't apply to a static site with no protected resources. I want to write down what scored, what didn't, and where I think the scoring loses signal.
